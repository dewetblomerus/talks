# Talks

A monorepo for my conference and meetup talks. Each directory holds one talk — notes, outline, and slides — where I iterate before presenting and keep everything archived afterwards.

## Marp

Slide decks are Markdown files with a `marp: true` front matter block, rendered by [Marp](https://marp.app/). This keeps slides diffable in git and editable in any editor, and exports to HTML or PDF when it's time to present.
